**Aim**
To Design a Basic Mobile and Web Layout for an Existing Case Study

**Algorithm**
Apply Gestalt principles to enhance mobile and web layout design. Incorporate UI elements and design patterns into the layouts. Develop interaction behaviors and usability principles for the designs. Create a brand logo using Canva, following styling and branding guidelines and include it with your layouts.

**Output**
Designing a Basic Mobile and Web Layout for Swiggy – Case Study

1:Applying Gestalt Principles to Enhance Design:
Gestalt principles play a crucial role in improving the visual hierarchy and usability of the Swiggy layout. The principle of proximity is applied by grouping restaurant images, names, delivery time, cuisine type, and ratings within clearly defined cards. This allows users to scan essential information quickly without confusion. The principle of similarity is maintained by using consistent color schemes for action buttons like “Order Now” and “Track Order,” as well as uniform typography for headings and descriptions. This consistency builds familiarity and reduces learning time for users.

Continuity is reflected through vertically scrollable restaurant listings and horizontally scrollable category sections such as “Popular Near You,” “Offers,” and “Top Rated.” These structured flows naturally guide user attention. The principle of closure is achieved by using soft shadow cards and partially framed promotional banners, allowing users to visually complete shapes without heavy borders. The figure/ground principle ensures that important call-to-action buttons stand out using Swiggy’s signature orange color against a neutral white background, enhancing clarity and focus.

2:Incorporating UI Elements and Design Patterns:
The mobile layout integrates essential UI components for intuitive navigation. The top navigation bar includes the Swiggy logo, location selector, and search icon. Below it, category chips such as “Biryani,” “Pizza,” “Healthy,” and “Offers” allow quick filtering. Restaurant listings are displayed as vertical cards showing image previews, rating badges, estimated delivery time, cuisine details, and price range. A bottom navigation bar includes Home, Search, Cart, and Account sections for seamless switching between features.

For the web layout, a structured header displays the logo, search bar, offers section, help center, and user profile options. A left-hand filter panel allows sorting by ratings, price range, dietary preference, and delivery time. The main content area uses a responsive grid layout that adjusts depending on screen size, ensuring consistency across desktop and tablet devices. Design patterns such as modal pop-ups for viewing menus, toast notifications for cart additions, and progress indicators during checkout improve user experience.

3:Developing Interaction Behaviors and Usability Principles:
Interaction design focuses on responsiveness and clarity. When users tap “Add to Cart,” the button animates slightly and updates the cart count instantly, providing immediate feedback. On the web layout, hover effects highlight clickable cards, while smooth transitions enhance perceived performance. Affordances are clearly indicated—buttons appear raised, clickable text is underlined, and interactive elements have visual feedback.

Mobile interactions include swipe gestures for browsing food categories and pull-to-refresh functionality. The web layout ensures adaptive responsiveness, resizing content proportionally for different screen resolutions. Accessibility considerations include readable font sizes, sufficient color contrast, alt text for images, and logical tab ordering for keyboard navigation. The checkout process is streamlined into minimal steps to reduce friction and enhance task completion rates.

4:Creating a Brand Logo Using Canva:
The Swiggy logo was recreated using Canva by following modern branding guidelines. The design features a bold, minimal icon paired with clean sans-serif typography. The primary brand color (orange) symbolizes energy, speed, and appetite stimulation. The logo maintains scalability for both mobile app icons and web headers. Proper spacing and alignment ensure clarity across different screen sizes. The final logo is integrated into both mobile and web layouts to maintain brand consistency.
